### 2.1 关键发现：表情文件的实际成本

单个表情文件全文：

```json
{
    "Type": "Live2D Expression",
    "IsModelCustomizationExpression": false,
    "Parameters": [
        { "Id": "Param15", "Value": 1.0, "Blend": "Add" }
    ]
}
```

**所谓「11 个功能键」并不包含 11 套动画**，本质是 11 个「把某个参数设为 1.0」的赋值文件；键盘 0–9 的触发出现在 `.vtube.json` 的 `Hotkeys` 中。

**结论**：表情与文件族外壳是项目中最容易自动化的部分，也因此**不构成产品价值**。价值集中在 `.moc3` 内的第 ④ 层（见决策 0001 第 2.1 节）。

## 三、`model3.json` 结构

```json
{
  "Version": 3,
  "FileReferences": {
    "Moc": "<name>.moc3",
    "Textures": ["<name>.2048/texture_00.png", "<name>.2048/texture_01.png"],
    "Physics": "<name>.physics3.json",
    "DisplayInfo": "<name>.cdi3.json"
  },
  "Groups": [
    { "Target": "Parameter", "Name": "EyeBlink", "Ids": [] },
    { "Target": "Parameter", "Name": "LipSync",  "Ids": [] }
  ]
}
```

**注意**：`EyeBlink` 与 `LipSync` 两个标准组的 `Ids` 为**空数组**。因此对该模型而言，VTS 面捕的眨眼 / 口型同步**不能依赖这两个组**，只能依赖标准参数名（`ParamEyeLOpen` / `ParamEyeROpen` / `ParamMouthOpenY`）。这提示：

> 若我们的输出要保证 VTS 面捕可用，**必须显式填充 `EyeBlink` / `LipSync` 组的 `Ids`，或严格使用标准参数 ID**。验收时须实测，不能假定。

### 4.2 自定义参数（31 个）

- **物理驱动参数**（由 `.physics3.json` 输出）：`Param_Angle_Rotation_{1,2,3}_ArtMesh{,_4,_5,_41,_42,_43,_44,_62,_63}` —— 共 27 个，用于刘海（3 组）、侧发（左右各 2 组）、耳朵（左右各 1 组）的旋转
- **按键开关参数**：`Param` `Param2` `Param7` `Param8` `Param9` `Param10` `Param12` `Param13` `Param14` `Param15` `Param16`
- **物理与隐藏信息**：`Param11`（ZZZ 物理）、`Param3`（分隔线）、`Param4` `Param5` `Param6`

### 4.3 值得注意的圈内惯例

`Param4`–`Param6` 的**参数名本身就是文字**：

```
Param4 | 本模型版权属于：
Param5 | 小野辣条
Param6 | B站工坊售卖中
```

另有 `Param3 | --------------分割线---------------`。

**这是中文皮套圈的常见做法：用「永不参与动画」的参数名承载作者信息与说明文字**（在 Cubism Editor 的参数列表中形成一块可读的信息面板）。

对我们的启示：参数命名空间会被终端作者用于元信息，工具生成参数时**不应假定 `Param*` 全部可用**，应采用带命名空间的自定义参数 ID，并保留可读的显示名。

### 4.4 参数组（13 个）

## 六、物理结构（5 条链）

| 链 | 名称 | 输入 | 输出 |
|---|---|---|---|
| PhysicsSetting1 | 裙子的摇动 | `ParamBodyAngleX` | `ParamSkirtSway` |
| PhysicsSetting2 | 刘海 | `ParamAngleX` `ParamAngleZ` `ParamBodyAngleX` `ParamBodyAngleZ` | `Param_Angle_Rotation_*_ArtMesh` `_4` `_5`（9 个，3 组 × 3 段） |
| PhysicsSetting3 | 侧发 | 同上 | `_ArtMesh41/42/43/44`（12 个，4 组 × 3 段） |
| PhysicsSetting4 | 耳朵 | 同上 | `_ArtMesh63/62`（6 个，2 组 × 3 段） |
| PhysicsSetting5 | ZZZ 物理 | 同上 | `Param11` |

`Meta`：`PhysicsSettingCount=5`、`TotalInputCount=17`、`TotalOutputCount=29`、`VertexCount=16`、`Fps=60`、重力 `(0,-1)`。

**观察**：头发类物理均为「角度输入 → 分段旋转输出」，每部位 **3 段**。这一模式**可高度模板化**（给定部位数量与分段数即可生成链结构），但阻尼 / 摆幅等质感参数须逐模型调整。

## 七、`.vtube.json` 结构（VTS 专属，68 KB）

顶层字段（20 个）：

```
Version, Name, ModelID, FileReferences, ModelSaveMetadata,
SavedModelPosition, ModelPositionMovement, ItemSettings,
PhysicsSettings, GeneralSettings, ParameterSettings, Hotkeys,
HotkeySettings, ArtMeshDetails, ParameterCustomization,
PhysicsCustomizationSettings, FolderInfo, UserCustomization,
SavedActiveExpressions, ModelFolder
```

其中对验收有直接意义的字段：

| 字段 | 含义 |
|---|---|
| `Hotkeys` / `HotkeySettings` | 键盘热键绑定（对应「按键列表.TXT」） |
| `ParameterSettings` | 参数自定义（重命名、范围、默认值） |
| `PhysicsSettings` | VTS 侧物理开关与强度（`UseLegacyPhysics`、`Live2DPhysicsFPS`、`PhysicsStrength`、`WindStrength`、`DraggingPhysicsStrength`） |
| `ArtMeshDetails` | 可钉住排除列表、ArtMesh 分组、光照倍率 |
| `GeneralSettings.WorkshopSharingForbidden` | 禁止创意工坊分享（版权标记） |
| `ModelPositionMovement` / `SavedModelPosition` | 模型位置与移动平滑 |

**注意**：`.vtube.json` 属于**运行时用户配置**（含保存时间戳、保存次数），不是模型本体。工具**不应把它当作必需交付物**；如需生成，只应生成默认模板，绝不覆盖用户已有配置。

### 8.2 内部质量基线（对标用，非承诺值）

| 指标 | 参考样本 | 我们第一版目标 |
|---|---|---|
| 标准 Cubism 参数 | 45 | ≥ 45（命名规范一致） |
| 物理链 | 5 | ≥ 1（可模板化） |
| Part 层级 | 45，含蒙皮 + 旋转变形器 | 层级完整，**不承诺蒙皮骨骼** |
| 纹理图集 | 2 × 2048² | 尺寸合规 |
| 残余项 | 有 2 处「未找到对应图层」 | **0 处** |

### 8.3 必须明确区分的两件事

> **「文件格式达标」与「质量达标」不是一回事。**
> 格式达标：可加载、参数规范、清单完整——**我们能做到并承诺。**
> 质量达标：变形自然、物理不穿帮、细节精细——**不承诺**，须如实标注已验证功能与已知限制（v0.3 文档 13 章要求）。
