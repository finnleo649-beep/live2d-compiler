# 决策记录 0004：文档版本递增规则

- **日期**：2026-10-15
- **状态**：已采纳（用户确认）
- **适用范围**：`Live2D_Compiler` 项目书（docx）及配套 `docs/decisions/` 决策文档

---

## 一、规则

1. **版本基准**：以项目书文件名 `Live2D_Compiler_v2.docx` 的 **v2** 为当前版本基准。
2. **每次有实质变动，版本号向后递增。**
3. **递增标准（建议，可调整）**：
   - 小改（局部修订、修正、补充几节内容）→ `v2.1`、`v2.2`、…
   - 大改（定位、架构、目标用户等根本性调整）→ `v3`、`v4`、…
4. **每次变动必须执行**：
   - 先备份旧版（`Live2D_Compiler_vN.backup.docx`，或归档保留历史版本）
   - 更新文档**标题**与**版本行**
   - 在文档顶部「修订说明」记录本次变更内容
5. **一致性**：文档内部标题的版本号与文件名版本号必须一致。
