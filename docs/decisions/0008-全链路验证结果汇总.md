## 五、已知限制（如实记录）

1. **分辨率**：目前 1024px 稳定；1280px 在 8GB 上未验证。
2. **质量上限**：自动绑定质量**必然低于手工绑定**（官方 see-through 与 psd2live 均如此声明）。这是"半成品/起点"的定位，符合 0001 决策。
3. **难例**：白发+白围裙等颜色/空间重叠的角色，分层可能有误判（见 0006）。
4. **许可证**：see-through（研究项目）、psd2live（GPL-3.0）、LayerDiff3D/Marigold/SAM 的商用许可**均需审查**，商用前必须完成。
5. **Java 临时目录**：psd2live 运行时必须设 `JAVA_TOOL_OPTIONS=-Djava.io.tmpdir=<工作区>`，否则纹理图集生成失败。
