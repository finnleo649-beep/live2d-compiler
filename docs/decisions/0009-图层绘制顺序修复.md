# 决策记录 0009：图层绘制顺序修复（配件遮挡问题）

- **日期**：2026-10-18
- **状态**：已实现并验证核心假设
- **解决的问题**：发箍/配件被头发遮挡、转头时配件与头发分离（用户实测反馈）

---

## 一、问题

用户实测反馈（模型 gen_240776）：

> 转头和眨眼都不自然，会穿模。头上的发箍和头发分离，不够精细。

诊断发现 `psd2live` 输出的绘制顺序（从底到顶）：

```
 0  back hair
 ...
 6  headwear      ← 发箍在这里（第 7 层）
 7  ears
 8  face
 ...
16  front hair    ← 前发在最顶层，把发箍整个盖住
```

**发箍被压在前发下面**，视觉上表现为「分离/消失」。

---

## 二、根因分析

`psd2live` 的排序逻辑（`_probe_git/src/main/kotlin/io/github/psd2live/application/WorkspaceLayoutEdits.kt` 第 137 行）：

```kotlin
/** The source layers top-most first: the stack the generator draws in, by `order` and then by place in the list */
fun stack(source: SourceArt): List<SourceLayer> =
    source.layers.withIndex().sortedWith(compareBy({ it.value.order }, { it.index })).map { it.value }
```

**结论：psd2live 的 drawOrder = PSD 图层的 `order`（即 PSD 图层顺序）。**

而 see-through 输出的 PSD 顺序是按语义分类排列的，**不保证符合视觉层次**
（实测 `headwear` 可能排在 `front hair` 之前）。

因此：**问题不在 psd2live，而在 see-through 输出的 PSD 图层顺序。**

---

## 三、修复方案

在把 PSD 交给 psd2live **之前**，按视觉层次重排图层：

```
back hair（最底）
  tail / wings
  body / neck
  legwear / footwear
  handwear
  bottomwear / topwear
  objects
  ears
  face / nose / mouth
  eyebrow / eyewhite / irides / eyelash
  front hair
  headwear / earwear / eyewear（最顶：配件应当可见）
```

实现：`pipeline/stages/reorder_psd.py`

```python
from pipeline.stages.reorder_psd import reorder_psd
report = reorder_psd(src_psd, dst_psd)
# report = {"before": [...], "after": [...], "moved": [...]}
```

- 保持每个图层的**名字、位置偏移、透明度、可见性**不变
- 只改变堆叠顺序
- 未知图层放最顶（避免被遮挡而消失）
- 同优先级图层保持原有相对顺序（稳定排序）

已接入 `generate_model.py` 的 `[2.5/3] 修正图层绘制顺序` 步骤。

## 四、验证结果

### 4.1 单元测试（构造 PSD）

输入（乱序）：`headwear, front hair, face, back hair, eyelash`
输出（重排后）：`back hair, face, eyelash, front hair, headwear`

所有顺序断言 PASS，图层数据（left/top/opacity/visible）完整保留。

### 4.2 真实 PSD 重排

see-through 输出的 14 层 PSD（角色无头饰）：

| 重排前 | 重排后 |
|---|---|
| back hair, legwear, handwear, bottomwear, **neck**, topwear, ears, face, mouth, **eyewhite, eyebrow**, irides, eyelash, front hair | back hair, **neck**, legwear, handwear, bottomwear, topwear, ears, face, mouth, **eyebrow, eyewhite**, irides, eyelash, front hair |

调整了 6 个图层。

### 4.3 关键验证：psd2live 是否跟随新顺序

用重排后的 PSD 跑 psd2live，其诊断报告（`*.psd2live.json`）的 `layers` 顺序：

```
 0  back hair
 1  neck          ← 重排前在 legwear 之后，现在提前 ✅
 2  legwear
 3  handwear
 4  bottomwear
 5  topwear
 6  ears
 7  face
 8-10 mouth（上唇/下唇/嘴）
11  eyebrow       ← 重排前在 eyewhite 之后，现在提前 ✅
12  eyewhite
13  irides
14  eyelash
15  front hair
```

**psd2live 的输出顺序完全反映重排后的 PSD 顺序** → 方案有效，无需修改 psd2live 源码。

        sys.path.insert(0, _p)
