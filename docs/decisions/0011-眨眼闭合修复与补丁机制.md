# 决策记录 0011：眨眼闭合修复 + psd2live 本地补丁机制

- **日期**：2026-10-18
- **状态**：已实现，待用户实机确认
- **解决的问题**：用户反馈「眨眼不自然」

---

## 一、问题与根因

用户反馈眨眼不自然。排查 psd2live 源码后定位到 `RigBuilder.kt` 的 `eyeClosurePoint()`：

```kotlin
val edgeY = eyeWhiteBounds.top + eyeWhiteBounds.height * tuning.blinkCorner / 100f
val curveY = edgeY + max(1.5f, eyeWhiteBounds.height * tuning.blinkDepth / 100f) * arch
```

**闭合曲线位置 = blinkCorner + blinkDepth**，默认值：

```
34% + 38% = 72%
```

即：眨眼时眼睛只闭到眼白高度的 **72%**，剩下的 28% 永远睁着 → 视觉上像「半闭眼」。

另外，psd2live **没有独立眼睑层**，眨眼是通过把 `eyelash`/`eyewhite` 网格压向闭合曲线来模拟的。

---

## 二、修复

| 参数 | 原值 | 新值 |
|---|---|---|
| `blinkCorner` | 34% | **20%** |
| `blinkDepth` | 38% | **75%** |
| `eyelashSquash` | 88% | **80%** |
| **闭合度** | 72% | **95%** |

同时给 psd2live CLI 新增三个参数（原来完全不暴露）：

```
--blink-depth <0..80>     默认 75
--blink-corner <0..80>    默认 20
--eyelash-squash <0..150> 默认 80
```

改动三处（`Main.kt`）：
1. `import io.github.psd2live.core.RigTuning`
2. `PipelineConfig(... rigTuning = RigTuning(...))`
3. `CliOptions.valueNames` 增加三个参数名

---

## 三、持久化机制（重要）

`_probe_git`（psd2live 源码目录）**不进 git 仓库**——它由 `setup.py` 下载。
所以本机改了源码，别人 clone 后不会生效。

解决方案是**patch 机制**：

1. **`patches/psd2live-blink.patch`**：完整的 unified diff（存档 + 人工审查）
2. **`setup.py` 的 `apply_psd2live_patches()`**：下载源码后自动应用补丁
   - 用 Python 字符串替换实现（不依赖 `git apply` / `patch` 命令）
   - **幂等**：已应用则跳过
   - 源码结构变化导致失配时给出警告并指向 patch 文件
